# HT Lab

面向自学的**闯关式学习网页**：纯静态、零后端，双击 `index.html` 就能用，学习进度只保存在访问者自己的浏览器里。

## 现有课程

| 课程 | 关卡 | 内容 |
| --- | --- | --- |
| C 语言 | 86 关 | 起步上路 8 · 流程控制 8 · 函数与程序结构 8 · 数组与字符串 8 · 指针与内存 10 · 自定义类型与数据结构 8 · 文件与输入输出 6 · 预处理器与工程实践 8 · 数据结构与算法 10 · 系统与底层 6 · 综合项目 6。每关：讲透原理 → 可编译运行的示例与真实输出 → 常见陷阱 → 知识快问 → 动手代码挑战（结构检查 + 本机运行结果比对）→ 标准答案 → 掌握标准 |
| 英语四级 | 62 关 | 地基 8 · 听力 12 · 阅读 14 · 写作 8 · 翻译 8 · 口语 10 · 全真模考 2。听说读写全链路：听力与口语带合成音频，写作与翻译按「要点 + 字数」自动判分，口语支持录音回放与自评，模考带倒计时与交卷判分 |

两门课的进度、学习点与统计各自独立保存；进入「学习课程」页选择课程，进入后是这门课自己的学习路线。

## 本地使用

直接双击 `index.html` 即可（`file://` 下录音功能可用，浏览器会询问麦克风权限）。

若偏好本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 音频生成（内容作者用，不需要随站点发布）

站点音频由 [edge-tts](https://github.com/rany2/edge-tts) 语音合成生成，脚本为 `work/gen_audio.py`：

```bash
python -m pip install --target ./work/tts edge-tts
python work/gen_audio.py            # 增量生成缺失的音频
python work/gen_audio.py --check    # 只校验：文件是否存在、时长是否正常
```

多角色对话（男女声交替）由分段合成后用 ffmpeg 拼接，生成记录写在 `audio/cet4/dialogue.json`。
